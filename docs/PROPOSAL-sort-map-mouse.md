## 1. 鼠标操作缩放(增强现有能力)

**现状(已实现,无需重做)**:滚轮以光标为锚点缩放、左键拖动平移、双击「适应 ↔ 1:1」、工具栏 ± 按钮、键盘 +/−/0/1。

**本次新增**:

| 项 | 做法 | 说明 |
|---|---|---|
| 触控板双指捏合 | 接入 egui `zoom_delta()`(已确认存在),与滚轮统一走 `viewer.zoom_at` 缩放核心 | 触控板用户最自然的缩放手势 |
| 中键拖动平移 | 中键按下即可平移(与左键等效) | 避免左键拖动与选择/双击手势的相互干扰 |
| 滚轮语义可选 | 设置项:「滚轮=缩放」(默认,现行为)/「滚轮=翻页,Ctrl+滚轮=缩放」 | 两派习惯都有(IrfanView 派 vs 现代派),先做开关常量,M3 设置面板接入 |

不做:缩放惯性动画、flick 惯性滚动(收益小、复杂度高,维持"简单优先")。

**工作量**:约 0.5 天(含 2 个单测:`zoom_delta` 路径的锚点不漂移、中键路径)。

## 2. 排序:名称 / 大小 / 类型 / 创建日期

**数据模型**:目录扫描时单次收集元数据,构造有序表(网格与浏览共用):

```rust
struct ImageEntry {
    path: PathBuf,
    size: u64,
    modified: SystemTime,
    created: Option<SystemTime>,  // Linux statx btime;缺失则 None
    ext: String,                   // 小写扩展名,用于"类型"排序
}
```

**排序键**(升降序可切换):

| 键 | 规则 |
|---|---|
| 名称(默认) | 不区分大小写 + **自然序**(`IMG_2` < `IMG_10`,数字段按数值比较),自实现 ~30 行 |
| 大小 | 字节数 |
| 类型 | 扩展名,同名再按名称 |
| 修改日期 / 创建日期 | 时间戳;**创建时间不可用时回退为修改时间**,并在 UI 标注提示 |

**交互**:工具栏加一个下拉(egui ComboBox:名称/修改时间/创建时间/大小/类型)+ 升降序切换按钮(↑↓)。切换后:
- 网格即时重排;**浏览模式保持当前图片**,索引重定位到新位置;
- 缩略图缓存按「路径+时间+大小」做键,排序变化零影响。

**平台注**:Linux 的创建时间依赖内核/文件系统 btime(本机 ext4 + statx 实测可用,见附录);Windows / macOS `created()` 原生可用。

**工作量**:约 1 天(含排序纯函数单测:自然序、类型、缺失 created 的回退)。

## 3. 地图模式(照片地理分布)

### 3.1 数据链路

- **GPS 提取**:kamadak-exif 直接支持 GPS 标签(已核实其官方测试即以 `exif.get_field(Tag::GPSLatitude, In::PRIMARY)` 读取);HEIC/AVIF 走既有 libheif 元数据通道,复用同一 TIFF 解析器。
- 解析:3 个 rational(度/分/秒)→ 十进制度,`N/S/E/W` 定符号;海拔可选。
- `ExifSummary` 新增 `gps: Option<(f64, f64)>`(纬度/经度,6 位小数保存);**信息面板新增「位置」行**。
- 提取时机:**在缩略图 worker 里顺带完成**(仅读文件头,微秒级),随网格加载并行铺开,不阻塞 UI;结果随 entry 缓存。

### 3.2 底图(离线内置,零网络依赖)

- 数据:**Natural Earth 110m**(public domain 衍生,npm `world-atlas` 2.0.2,ISC 许可),已从 npmmirror 拉取(附录 A)。
- 选型:**countries-110m**(108 KB,含陆地 + 国界,地图可读性好);构建期一次性脚本:TopoJSON → 精简 GeoJSON(3 位小数)→ 随二进制 `include_bytes!` 打包。
- 投影:**等距圆柱**(lon→x, lat→y)。照片地图够用;墨卡托会把极地拉爆,不用。
- 渲染:世界多边形在启动时一次性投影为 egui Shape 缓存(约数千点),平移/缩放只做变换矩阵,帧率无压力。

### 3.3 交互

- 第三种中心视图 `Mode::Map`,工具栏「地图」按钮与网格/浏览并列切换(复用 Viewer 的平移/缩放数学,缩放范围 clamp 到"全球 ~ 城区")。
- 照片标记:小圆点(强调色描边);
  - 悬停 → 文件名 tooltip;
  - 单击 → 选中(右侧信息面板联动显示该图信息与坐标);
  - 双击 → 进入浏览模式(直接开始看图)。
- 邻近聚合:屏幕距离 < 18px 的标记合并,显示数量徽标(放大自动散开)。
- 空态:当前目录没有带 GPS 的照片 → 图中提示"该目录没有位置信息"。

### 3.4 明确不做(本轮)

- 在线地图瓦片(OSM 等):需要联网、有使用条款约束,与"离线可用"冲突 → 后续作为可选增强再评估。
- 逆地理编码(显示"北京"这种地名):需要在线服务或几十 MB 地名库,先只显示坐标。

**工作量**:约 2.5~3 天(含 GPS 解析单测、TopoJSON→GeoJSON 转换脚本、地图渲染截图验证)。
